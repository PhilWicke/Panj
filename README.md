# Slovelingo

Slovelingo is an installable web app for learning everyday Slovenian, aimed at someone who wants to talk with their hosts and the people around them. Short daily sessions mix new words and phrases with spaced review, and the app runs offline on a phone once it has been added to the home screen. There is no account and no server: progress stays on the device.

To run it locally you need Node 24 or later and nothing else, since the project has no dependencies. Run `npm run serve` from the project folder and open http://localhost:4173 in a browser. Run `npm test` to run the test suite.
